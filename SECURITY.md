# Politique de sécurité

## Signaler une vulnérabilité

Écrivez à **visacheckercontact@gmail.com** avec l'objet « Sécurité » et :

- la page ou le composant concerné (site, Worker, assistant IA) ;
- les étapes pour reproduire le problème ;
- l'impact que vous constatez.

N'envoyez jamais de vrais documents de voyage ni de données personnelles de tiers dans votre signalement.
Nous accusons réception sous 7 jours. Merci de ne pas rendre le problème public avant correction.

## Ce que le projet ne doit jamais contenir

Aucune clé API, aucun secret, aucune URL de webhook, aucun numéro de passeport ni scan de document dans ce dépôt.
Les secrets vivent uniquement dans les variables chiffrées de Cloudflare.
